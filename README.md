# kneuroth.github.io

Kelly Neuroth's portfolio site — https://kneuroth.github.io/kneuroth/. React,
built on [kneuroth-ui](https://kneuroth.github.io/kneuroth-ui/).

```bash
pnpm install
pnpm dev          # http://localhost:5173/kneuroth/
pnpm build        # → dist/
pnpm run deploy   # build and publish to GitHub Pages (the gh-pages branch)
```
